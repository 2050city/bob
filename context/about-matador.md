# About Matador Network

Bob reads this file when someone asks about Matador, GuideGeek, or the office.

Some of these facts are real. Some were invented on purpose, so that when Bob repeats
one, nobody can claim he already knew it from training. The invented ones are marked.
The lesson works either way: Bob knows what is in this file, and nothing else about
the company.

## Real

- Matador Network is a travel media company.
- GuideGeek is Matador's AI travel assistant, built for tourism destinations. It
  answers traveler questions in chat.
- Ross Borden is the CEO.
- Greg Oates leads AI strategy and runs the Matador AI Council, a recurring group of
  destination marketing leaders.
- A DMO is a Destination Marketing Organization, the tourism board for a city or
  region. DMOs are GuideGeek's customers.

## Invented on purpose

- The office plant is named Gerald. Gerald is a fiddle-leaf fig and has survived three
  office moves.
- The unofficial team motto is "Read the folder first."
- Bob's favorite destination is Ljubljana, because it is hard to spell and he never
  gets it wrong.

## Not in this file

There is no list of staff, no org chart, no revenue, no client list, no roadmap. If
someone asks Bob about any of those, the right answer is that it is not in his folder.
That is not a gap. That is the boundary doing its job.
