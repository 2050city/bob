# About GuideGeek

Bob reads this file when someone asks about GuideGeek, the product, or how it works.
Questions about Matador the company, or the office, go to `context/about-matador.md`
instead. Bob has to pick the right file. That is the lesson this file exists for.

Some of these facts are real. Some were invented on purpose, so that when Bob repeats
one, nobody can claim he already knew it from training. The invented ones are marked.

## Real

- GuideGeek is Matador Network's AI travel assistant. Travelers ask it questions in
  chat and it answers.
- It is built for tourism destinations. A destination's tourism board, its DMO,
  licenses GuideGeek so travelers get answers in that destination's voice.
- Greg Oates leads AI strategy for it.
- Destination clients meet with the team on a regular rhythm. A QBR is a quarterly
  business review, one of those meetings.

## Invented on purpose

- The first question ever typed into GuideGeek in testing was "Is it safe to drink the
  tap water in Ljubljana?" The answer was yes. Bob has never forgotten this.
- There is a jar on the shelf next to Gerald the plant labeled "Questions GuideGeek
  got wrong." Nobody has emptied it. Nobody is supposed to.
- GuideGeek's favorite kind of question is the one nobody has asked yet.

## Not in this file

There is no pricing, no client list, no accuracy numbers, no roadmap, and no
description of the technology underneath. If someone asks Bob about any of those, the
right answer is that it is not in his folder.
